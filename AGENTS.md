# CAVALRY-I18N KNOWLEDGE BASE

Last verified: 2026-06-02 | Commit: bf733dd | Branch: main | Target: Cavalry 2.7.2 | Qt: 6.6.3 | Runtime: macOS only

## OVERVIEW

Cavalry-i18n is a macOS-only Tauri desktop language switcher for Cavalry. It patches Cavalry JSON assets, installs a DYLD runtime translator, patches Keychain query behavior, re-signs the local `Cavalry.app`, clears quarantine, and relaunches Cavalry in English, Simplified Chinese, Traditional Chinese, or Japanese.

Stack: vanilla HTML/CSS/JS renderer + Tauri 2 Rust backend + Objective-C++ Qt injector + Node/Python/Bash gate tooling. This is not a generic i18n repo; it is a local app-bundle patcher with runtime UI translation gates.

## CONVENTIONS

### Agent startup

- Start with `git status --short --branch`, `CLAUDE.md`, and the nearest module `CLAUDE.md`.
- For a business file, verify the L3 header contract before editing. If missing, add it first.
- Do not create a branch, commit, or push unless the user asks. This repo owner often expects direct `main` work.
- New root or module files require the matching `CLAUDE.md` map update in the same change.
- Communicate in Chinese, start user-facing replies with `哥`, and report evidence before claiming completion.

### Renderer

- `app.js` must not know Tauri internals. It talks only to `window.cavalryI18n`.
- `tauri-bridge.js` normalizes camelCase payloads only. Do not reintroduce snake_case fallbacks or debug fields.
- `index.html` ids are test anchors. Rename only with `tools/check_renderer_contract.js` and bridge/runtime tests updated.
- UI text is localized in `app.js`; translated Cavalry runtime UI belongs to `languages/` and `tools/*.ts`, not renderer shell copy.

### Tauri backend

- `commands.rs` is the renderer-facing API layer. Keep command count and JSON shape stable unless renderer and contract tests change together.
- `privilege.rs` is the only system-command boundary. Keep shell/admin/Finder fallback behavior there.
- `detect.rs`, `patch.rs`, `mac_runtime.rs`, `keychain_patch.rs`, and `state.rs` should stay mostly pure data/filesystem logic.
- State may be redirected with `CAVALRY_I18N_STATE_DIR`; tests depend on this separation.

### Translation surfaces

- There are two real surfaces: JSON-backed assets and compiled/runtime Qt UI text.
- `languages/en` is the JSON baseline. Target language directories must match structure and preserve non-translatable identity fields.
- `niceName`, API/type/id fields, and Time Editor model-backed values stay English when they are model identity, even if display-layer UI translates them elsewhere.
- `tools/*.ts` handles compiled/runtime display text. `tools/model_display_translations.json` is display-only and must not rewrite JSON model data.
- Allowlist or whitelist changes require evidence. Do not use them to hide untranslated or fabricated output.

### Injector and Qt

- The injector targets Cavalry 2.7.2's Qt 6.6.3 runtime. Do not add Qt API symbols without ABI verification.
- `QMenu::aboutToShow`, `ActionAdded`, and `Show` are first-paint translation paths. Avoid delayed menu fixes that visibly flash English.
- `QLineEdit` display translation must not mutate model identity. Time Editor item views and `QAbstractItemView` model roles preserve English where required.
- `QTextEdit` MessageBar handling is append-time only. Do not scan full QTextEdit documents during Paint/Show or inventory.
- ExtensionLayer self-painted UI is Latin-only and remains English; do not force CJK into that surface.

### Build and release

- Tauri is the only active desktop shell. Do not restore old Electron/fallback packaging paths.
- Internal app version is SemVer in `CHANGELOG.md`, `package.json`, `src-tauri/Cargo.toml`, and `src-tauri/tauri.conf.json`; sync with `npm run sync:version`.
- Public release tags are `cavalry-2.7.2-pN`, generated against `release.config.json`.
- The injector must be built against Qt 6.6.3 via `npm run build:injector` or the Tauri `beforeBuildCommand`.

## ANTI-PATTERNS

| Pattern | Why | Instead |
| --- | --- | --- |
| Treating CI green as full UI pass | CI records `BLOCKED-NO-LIVE-CAVALRY`; it cannot run Cavalry live capture | Run the local session-scoped full UI gate |
| Editing `generated_translations.inc` by hand | It is a generated C++ projection | Edit `tools/*.ts` or `model_display_translations.json`, then regenerate |
| Weak runtime inventory from cache root | Gate inputs must be session-scoped with provenance | Use `$SESSION_DIR/runtime/*` and `verify_gate_inputs.js` |
| Changing allowlists to pass coverage | Hides real translation debt | Fix source translations or add evidenced quarantine |
| Translating model `niceName` in JSON | Breaks Time Editor/model identity and may render CJK boxes | Keep model identity English; translate display layer |
| Adding raw Tauri invoke calls in `app.js` | Breaks renderer/bridge boundary | Extend `window.cavalryI18n` and tests together |
| Restoring old shell/build paths | Tauri-only path is the release contract | Use `LOCAL_BUILD_SOP.md` |
| Handwriting release title or DMG name | Drifts from tag protocol | Use `tools/release_metadata.js` |
| Editing real `/Applications/Cavalry.app` in tests | Tests must not mutate user apps by accident | Use fixtures or explicit manual smoke |
| Assuming `output/` is source truth | It is derived audit/draft material | Promote validated data into `languages/` |

## COMMANDS

```bash
# Setup
npm install

# Fast metadata and syntax checks
npm run check:version
npm run check:release
npm run check:app
npm run test:contracts

# Rust contracts
npm run check:tauri
npm run test:tauri

# Injector and Qt SDK
npm run prepare:qt-sdk
npm run build:injector

# Local Tauri build / package
npm run tauri:dev
npm run tauri:build
npm run build:tauri
npm run test:tauri:packaged
npm run test:tauri:dmg-layout
npm run test:tauri:ui

# Full UI live gate, requires real Cavalry.app
npm run extract:compiled-ui
node tools/run_live_full_ui_matrix.js --app /Applications/Cavalry.app
# Reuse the session UUID printed by run_live_full_ui_matrix.js
SESSION_DIR="$HOME/Library/Caches/Cavalry-i18n/sessions/<session-uuid>" npm run check:full-ui
```

Manual smoke is intentionally ignored by default:

```bash
npm run test:tauri:manual-smoke
```

## SECURITY

- This app modifies a local `Cavalry.app` bundle. App Management permission is expected.
- The release DMG is ad-hoc signed, not Apple Developer ID notarized. Do not claim notarization.
- `DYLD_INSERT_LIBRARIES` injection is intentional and limited to the patched Cavalry launcher wrapper.
- Keychain behavior is patched in `libExtensionLayer.dylib`; keep tests around per-function patch reports.
- Never commit real secrets, user caches, live session artifacts, or real Cavalry app bundles.
- `qt_sdk/`, `node_modules/`, `src-tauri/target/`, `src-tauri/gen/`, build outputs, and logs are ignored for a reason.
