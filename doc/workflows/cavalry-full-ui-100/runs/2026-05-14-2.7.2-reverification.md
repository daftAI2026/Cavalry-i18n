## Changes Applied During Re-verification

### FP-13 sourceText Fix
`tools/check_runtime_ui_coverage.js`: `buildCoverage` now passes `sourceText` to `detectForbiddenTranslationPatterns`. Without this, all translations containing "项目/項目" were falsely flagged as FP-13 regardless of the English source context, because the `allowedSourceRegex` check had no English source to compare against.

### Noise Filter Correction
The previous `dbc7fa6` commit added overly broad `_extraction_filters` regexes that excluded user-visible strings with existing .ts translations (e.g., "Lottie is a Pro Feature", "Office 365 Sheet Asset", "Create a Forge Dynamics Solver"). These regexes were removed. Only genuine binary noise / internal developer error patterns remain:
- Random binary noise (`Hbbbbbbbbaaaaaaaa`, `q )Zzc`, 3-letter codes)
- C++ internal errors (`cannot use`, `false literal`, `reserved prefix`)
- Well-known misspelled internal errors (`Missing 'direction' arguement`)
- HTTP auth noise (`Bearer`, `Bearer Token`)
- Copyright/Unicode/color noise (`2026 Scene Group Ltd`, `Lslash`, `Adobe RGB`)
- Internal developer errors (no .ts translations, not user-facing): `Invalid Path JSON in Clipboard`, `Missing 'name' or 'tag' argument`, `Node Preset dictionary must contain an 'id' key`

### Allowlist Expansion (`runtime_ui_allowlist.json`)
Added technical terms and keyboard shortcut fragments to accommodate legitimate English loanwords in Japanese/Chinese translations:
- `Professional`, `PNG`, `HTTP`, `MAT`, `Pro`, `Office`, `ZIP`, `Solvers`, `UI`, `ID`, `.cv`, `Dynamics`, `Shift`, `CA`
- Keyboard shortcut fragments: `"B "`, `" H"`, etc., `"'U'"`, `"「U」"`
- Parenthesized shortcut variants: `"（B"`, `"（H"`, `"（S"`

### New Translations (2.7.2 Delta)
Four compiled UI strings had no .ts translations in any language. These are the genuine 2.7.2 delta items:
- `Toggle this mode with the 'U' key` → translated to ja_JP, zh-Hant (zh-Hans already had it)
- `Invalid Path JSON in Clipboard, missing the 'path' key` → translated to ja_JP, zh-Hant (zh-Hans already had it)
- `Missing 'name' or 'tag' argument` → translated to ja_JP
- `Node Preset dictionary must contain an 'id' key` → translated to ja_JP

### Generated Translations
